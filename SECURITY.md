# Security policy

Do not report a suspected vulnerability in an issue, discussion, or pull request. Report it privately through [GitHub's private vulnerability reporting](https://github.com/dvmkit/dvmctl/security/advisories/new).

Include a safe reproduction using synthetic values, the affected CLI version, operating system, Node.js version, command, impact, and mitigation. Never send wallet secrets, seed phrases, API keys, tokens, real payment data, or customer data.

Do not move funds, access another person's data, or continue testing after a safe proof is established. We support the latest stable release only; this policy makes no response-time commitment.
